Part Number Manager

Automatic part-number generation & management for Windows (tkinter). Assembly / Part / Standard types, configurable prefixes and suffix length, never-reused numbers, Excel export, multi-user central mode.

Download GitHub Readme

Two editions, one UI

V1.0 — Local (SQLite)

No server needed. Each database is an independent SQLite file on your machine. Great for personal / single-PC use.

SQLiteOfflineExcel export

V2.0 — Central (PostgreSQL)

All data lives on a central PostgreSQL server (e.g. on your NAS via Docker). Account roles, multi-user collaboration, imports V1.0 databases.

Modern UI

Core features

Automatic part numbers

Type a part name and get a number instantly: Assembly / Part / Standard each with its own configurable prefix.

Never reused

Each type counts upward from prefix+0001; deleted numbers are never reassigned; edit collisions auto-increment.

Manage & search

Search by part number or name, edit, delete, and multi-select (Shift / Ctrl) for bulk operations.

Export to Excel

One click exports the whole database to a spreadsheet. Full import/export backup is supported.

Quick start

  1. V1.0: run the installer, create a database, start creating part numbers. No server required.
  2. V2.0: deploy the server first (V2.0/server/docker-compose.yml), then configure your server in V2.0/client/part_manager/config.py (host, port, database, role, password) and install the client.
  3. Full docs: V1.0 README · V2.0 README.
